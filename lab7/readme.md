# Лабораторная работа № 7. Работа с базами данных через JDBC

## Цель работы

Освоить подключение Java-приложения к базе данных через JDBC, выполнение SQL-запросов, создание и удаление таблиц, а также загрузку уникальных записей из JSON. В работе используется JDK 25 LTS.

## Краткая теория

JDBC предоставляет API для взаимодействия Java-приложения с базой данных. Для подключения нужен JDBC-драйвер выбранной СУБД. В примерах используется **H2**: она работает в памяти или в локальном файле и не требует установки отдельного сервера.

### Подключение JDBC-драйвера H2 в Maven

Чтобы использовать H2 в Java-проекте, необходимо добавить зависимость в файл `pom.xml`:

```xml
<dependency>
    <groupId>com.h2database</groupId>
    <artifactId>h2</artifactId>
    <version>2.2.224</version>
</dependency>
```

После добавления зависимости Maven автоматически скачает драйвер.

### Подключение к базе данных

База данных H2 может работать:

* **в памяти**: данные живут только в процессе работы программы;
* **в файле**: сохраняются в локальном файле (`~/musicdb.mv.db` в примере ниже).

Пример подключения **в памяти**:

```java
String url = "jdbc:h2:mem:testdb";
String user = "sa";
String pass = "";

try (Connection conn = DriverManager.getConnection(url, user, pass)) {
    // Работа с базой данных
}
```

Пример подключения **в файл**:

```java
String url = "jdbc:h2:~/musicdb";
try (Connection conn = DriverManager.getConnection(url, "sa", "")) {
    // Работа с базой данных
}
```

#### Создание таблиц

```java
String sql = "CREATE TABLE IF NOT EXISTS music (" +
             "id INT AUTO_INCREMENT PRIMARY KEY, " +
             "title VARCHAR(255) NOT NULL" +
             ")";
try (Statement stmt = conn.createStatement()) {
    stmt.execute(sql);
}
```

В примерах ниже предполагается, что соединение `conn` открыто и таблица `music` создана.

### Выполнение SQL-запросов через JDBC

#### SELECT

```java
String sql = "SELECT * FROM music";
try (Statement stmt = conn.createStatement();
     ResultSet rs = stmt.executeQuery(sql)) {
    while (rs.next()) {
        System.out.println(rs.getString("title"));
    }
}
```

#### INSERT

```java
String sql = "INSERT INTO music (title) VALUES (?)";
try (PreparedStatement ps = conn.prepareStatement(sql)) {
    ps.setString(1, "My Song");
    ps.executeUpdate();
}
```

#### UPDATE

```java
String sql = "UPDATE music SET title = ? WHERE id = ?";
try (PreparedStatement ps = conn.prepareStatement(sql)) {
    ps.setString(1, "New Title");
    ps.setInt(2, 1);
    ps.executeUpdate();
}
```

#### DELETE

```java
String sql = "DELETE FROM music WHERE id = ?";
try (PreparedStatement ps = conn.prepareStatement(sql)) {
    ps.setInt(1, 3);
    ps.executeUpdate();
}
```

Для передачи значений в SQL используйте параметры `PreparedStatement`. Нумерация параметров начинается с 1. Метод `executeQuery()` возвращает `ResultSet` для чтения результатов, а `executeUpdate()` выполняет изменение данных и возвращает число затронутых строк.

В примерах используются классы из пакета `java.sql`. Методы JDBC могут выбрасывать `SQLException`: обработайте его или укажите в сигнатуре вызывающего метода. `Connection`, `Statement`, `PreparedStatement` и `ResultSet` закрывайте через `try-with-resources`.

## Задания

### Исходные данные и подготовка

- [music-create.sql](./music-create.sql) — скрипт создания и заполнения таблицы `study.music` с полями `id` и `name`.
- [books.json](./books.json) — список посетителей и их любимых книг из лабораторной № 5.

Перед выполнением заданий с музыкальными композициями создайте схему `study` командой `CREATE SCHEMA IF NOT EXISTS study`, затем выполните скрипт `music-create.sql` в выбранной базе данных.

Выполните задания с помощью SQL-запросов и JDBC. Можно использовать H2 в памяти или в файле либо другую СУБД на свой выбор. При выборе другой СУБД при необходимости адаптируйте SQL-скрипт и подключите её JDBC-драйвер.

> **По желанию** можно запустить другую СУБД в Docker-контейнере и подключиться к ней через JDBC. Использование Docker в этой лабораторной не обязательно и не влияет на оценку.

### № 1. Список музыкальных композиций (1 балл)

Получите и выведите все записи из таблицы `study.music`.

### № 2. Фильтрация композиций (1 балл)

Получите и выведите композиции, в названиях которых **отсутствуют обе буквы `m` и `t`**, без учёта регистра.

### № 3. Добавление композиции (1 балл)

Добавьте любую свою любимую композицию с помощью `INSERT`.

### № 4. Загрузка данных из JSON (2 балла)

Используя файл `books.json`:

- проанализируйте структуру данных;
- создайте таблицы для **посетителей** и **книг**, если они ещё не созданы;
- добавьте данные из JSON в базу;
- добавляйте только **уникальные** книги и посетителей.

Структуру таблиц и способ определения уникальности записей выберите самостоятельно.

### № 5. Сортировка книг (1 балл)

Получите и выведите список книг, отсортированный по году издания. Используйте `ORDER BY` для выбранного вами столбца с годом издания.

### № 6. Книги до 2000 года (1 балл)

Получите и выведите книги, изданные **до 2000 года**, с помощью условия `WHERE` по году издания (`< 2000`).

### № 7. Добавление посетителя и книг (1 балл)

Добавьте информацию **о себе** и свои любимые книги в соответствующие таблицы. Прочитайте добавленные данные из базы и выведите их.

### № 8. Удаление таблиц (1 балл)

Удалите созданные таблицы посетителей и книг с помощью `DROP TABLE`.
